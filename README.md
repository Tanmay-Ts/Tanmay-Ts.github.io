# Tanmay Surte — Portfolio

Personal portfolio at **https://tanmay-ts.github.io/**.

A responsive static site with self-hosted fonts, original pixel artwork, project case studies, verified open-source contributions, and a downloadable résumé. No build step or third-party JavaScript is required.

## Preview

Serve this directory with any static HTTP server, such as `python -m http.server 4173`, then visit `http://localhost:4173`.

## Update

- Main content: [index.html](index.html)
- Visual design and responsive layouts: [styles.css](styles.css)
- Project notes, filters, dialogs, and motion preferences: [script.js](script.js)
- Résumé: [assets/Tanmay-Surte-Resume.pdf](assets/Tanmay-Surte-Resume.pdf)

GitHub Pages publishes from the root of `main`. Push to `main` to update the site. Open-source PR statuses were verified on 22 October 2026; update the date when rechecking them.

Project interface visuals are illustrative schematics, not live product screenshots. Metrics are scoped to the linked evaluations. Ongoing research and draft/open contributions are labeled accordingly.

## Fonts

Space Grotesk, Syne, and IBM Plex Mono are self-hosted under their respective SIL Open Font Licenses; license texts are included in [assets/fonts](assets/fonts).

## Accessibility

The site supports keyboard navigation, native modal dialogs, visible focus states, an explicit motion pause control, OS reduced-motion preferences, and readable content when JavaScript is unavailable. Contact uses a standard email link.
